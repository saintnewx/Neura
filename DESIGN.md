# Дизайн-система Neura

Система опирается на принципы интерфейсов Linear: ясную иерархию, спокойные поверхности, точную типографику и короткие функциональные анимации. Цвета и параметры ниже принадлежат Neura. Документ задаёт целевой стандарт для новых компонентов и обновлений интерфейса.

## Основные принципы

- Содержание и главное действие имеют приоритет над декоративными эффектами.
- Иерархию задают размер текста, интервалы и контраст поверхностей.
- Тонкие границы отделяют карточки и элементы управления; яркий цвет используется точечно.
- Повторяющиеся элементы используют общие токены и одинаковое поведение.

## Цветовые токены

| Токен | Значение | Назначение |
| --- | --- | --- |
| `bg` | `#0B0D17` | Основной фон страницы. |
| `card` | `#13162A` | Карточки, панели и приподнятые поверхности. |
| `accent` | `#00E5FF` | Единственный основной акцент: главные действия, ссылки, активные состояния и индикатор фокуса. |
| `accent-2` | `#A259FF` | Второй цвет только внутри градиентов. |
| `text` | `#E6E9F5` | Основной текст и заголовки. |
| `muted` | `#8B90B0` | Подписи и второстепенный текст. |
| `line` | `#2A3050` | Границы карточек, полей и разделители. |

### Один основной акцент

Используйте `accent` как единственный самостоятельный акцентный цвет. `accent-2` допустим только как часть градиента, например `linear-gradient(135deg, #00E5FF, #A259FF)` для основного CTA или фирменного элемента.

Не используйте `accent-2` отдельно для текста, иконок, фона, границ, теней или состояний элементов. Второстепенные действия оформляйте через `text`, `muted` и `line`. Градиенты применяйте точечно, чтобы сохранить ясную иерархию.

## Типографика

Основной шрифт — **Inter Variable**, резервный — `system-ui, sans-serif`. Подключайте переменный файл шрифта с диапазоном весов, включающим `510` и `590`: статические начертания 500 и 600 не заменяют эти значения.

- Основной текст: `font-weight: 510`.
- Подзаголовки: `font-weight: 590`.

| Роль | Размер |
| --- | --- |
| H1 — главный заголовок | `80px` |
| H2 — заголовок секции | `48px` |
| Body — основной текст | `18px` |

Эти размеры задают типографическую шкалу для широких экранов. На мобильных устройствах уменьшайте H1 и H2 адаптивно, сохраняя иерархию. Для основного текста используйте межстрочный интервал `1.65`, для крупных заголовков — компактный интервал `1.05–1.15`. Подзаголовки остаются отчётливыми за счёт веса `590`, а не дополнительного акцентного цвета.

## Анимация

Анимация объясняет изменение состояния и даёт короткую обратную связь. Движение должно быть небольшим и предсказуемым.

- Длительность: **150–200ms**; `150ms` для небольшого отклика, `200ms` для появления и скрытия элементов.
- Кривая: **`ease-out`**.
- Анимируемые свойства: **только `transform` и `opacity`**.
- Появление: небольшое смещение через `translateY` вместе с изменением прозрачности.
- Hover: лёгкое изменение масштаба через `transform`, без сдвига соседних элементов.
- Цвет, границы и тени меняются сразу; размеры, отступы и позиционные свойства не анимируются. Не используйте `transition: all`.
- При `prefers-reduced-motion: reduce` отключайте переходы и анимации.

```css
.interactive {
  transition: transform 150ms ease-out, opacity 150ms ease-out;
}

.interactive:hover {
  transform: scale(1.02);
}

@media (prefers-reduced-motion: reduce) {
  .interactive {
    transition: none;
    animation: none;
  }
}
```

## Проверка новых элементов

Перед добавлением элемента сверяйте цвет с таблицей токенов, типографику — с заданными весами и размерами, а переходы — с ограничением `transform` / `opacity`. Убедитесь, что `accent-2` встречается только в градиентах и основной CTA остаётся визуально приоритетным.
