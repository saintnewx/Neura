# Дизайн-система Neura

Система опирается на принципы интерфейсов Linear: ясную иерархию, спокойные поверхности, точную типографику и короткие функциональные анимации. Цвета и параметры ниже принадлежат Neura. Документ задаёт целевой стандарт для новых компонентов и обновлений интерфейса.

## Основные принципы

- Содержание и главное действие имеют приоритет над декоративными эффектами.
- Иерархию задают размер текста, интервалы и контраст поверхностей.
- Тонкие границы отделяют карточки и элементы управления; яркий цвет используется точечно.
- Повторяющиеся элементы используют общие токены и одинаковое поведение.

## Цветовые токены — Apple × Linear

| Токен | Значение | Назначение |
| --- | --- | --- |
| `bg-base` | `#08090A` | Основной фон страницы. |
| `bg-elevated` | `#0F1011` | Приподнятые поверхности, поля и непрозрачные панели. |
| `card` | `rgba(255,255,255,0.025)` | Полупрозрачные карточки. |
| `card-hover` | `rgba(255,255,255,0.04)` | Карточки при наведении. |
| `border` | `rgba(255,255,255,0.08)` | Границы и разделители. |
| `border-hover` | `rgba(94,106,210,0.35)` | Акцентная граница при наведении. |
| `text-primary` | `#F5F5F7` | Основной текст и заголовки. |
| `text-secondary` | `#86868B` | Подписи и второстепенный текст. |
| `text-tertiary` | `#5A5A5F` | Плейсхолдеры и необязательные подписи. |
| `accent` | `#5E6AD2` | Основной акцент: ссылки, активные состояния и фокус. |
| `accent-soft` | `#00D9FF` | Редкие декоративные акценты. |
| `success` | `#30D158` | Успешные состояния. |
| `error` | `#FF453A` | Ошибки и валидация. |

Совместимые имена в Tailwind: `bg` → `bg-base`, `text` → `text-primary`, `muted` → `text-secondary`, `line` → `border`, `accent-2` → `accent-soft`, `accent-hover` → `accent`. Они используют те же значения, чтобы существующие компоненты оставались согласованными.

Для `card`, `card-hover`, `border` и `line` не добавляйте Tailwind-модификатор `/opacity`: он заменяет прозрачность RGBA-токена. Используйте `bg-card`, `border-border` и `divide-border` напрямую. Панели, где важна непрозрачность, используют `bg-bg-elevated`.

### Основные кнопки и акценты

Primary-кнопка: **`bg-white text-black rounded-full`**, без градиентного фона и цветного свечения. Это правило общее для лендинга, рабочей области, авторизации и модальных окон. Состояния фокуса и отключения сохраняются.

Основной акцент — `accent`; мягкий `accent-soft` используется точечно в декоре. Второстепенные действия используют нейтральные поверхности, основной текст и тонкие границы. Декоративные градиенты могут сочетать `accent` и `accent-soft`.

## Типографика

Основной шрифт — **Inter Variable**, резервный — `system-ui, sans-serif`. Подключайте переменный файл шрифта с диапазоном весов, включающим `510` и `590`: статические начертания 500 и 600 не заменяют эти значения.

- Основной текст: `font-weight: 510`.
- Подзаголовки: `font-weight: 590`.

| Роль | Размер |
| --- | --- |
| H1 — главный заголовок | `80px` |
| H2 — заголовок секции | `48px` |
| Body — основной текст | `18px` |

Эти размеры задают типографическую шкалу для широких экранов. На мобильных устройствах уменьшайте H1 и H2 адаптивно, сохраняя иерархию. Для основного текста используйте межстрочный интервал `1.65`, для крупных заголовков — компактный интервал `1.05–1.15`. Подзаголовки остаются отчётливыми за счёт веса `590`, а не дополнительного акцентного цвета.

## Анимация

Анимация объясняет изменение состояния и даёт короткую обратную связь. Движение должно быть небольшим и предсказуемым.

- Длительность: **150–200ms**; `150ms` для небольшого отклика, `200ms` для появления и скрытия элементов.
- Кривая: **`ease-out`**.
- Анимируемые свойства: **только `transform` и `opacity`**.
- Появление: небольшое смещение через `translateY` вместе с изменением прозрачности.
- Hover: лёгкое изменение масштаба через `transform`, без сдвига соседних элементов.
- Цвет, границы и тени меняются сразу; размеры, отступы и позиционные свойства не анимируются. Не используйте `transition: all`.
- При `prefers-reduced-motion: reduce` отключайте переходы и анимации.

```css
.interactive {
  transition: transform 150ms ease-out, opacity 150ms ease-out;
}

.interactive:hover {
  transform: scale(1.02);
}

@media (prefers-reduced-motion: reduce) {
  .interactive {
    transition: none;
    animation: none;
  }
}
```

## Проверка новых элементов

Перед добавлением элемента сверяйте цвет с таблицей токенов, типографику — с заданными весами и размерами, а переходы — с ограничением `transform` / `opacity`. Убедитесь, что основной CTA использует белый фон, чёрный текст и полное скругление, а карточки и границы сохраняют прозрачность своих токенов.
